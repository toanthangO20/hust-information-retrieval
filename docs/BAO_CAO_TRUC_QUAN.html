Lý do loại URL

URL hợp lệ theo trang con

  • Trùng lặp: SHA-1 nội dung (chính xác), canonical, SimHash 64-bit (gần đúng, chỉ gắn cờ).
  • Trang dựng bằng JavaScript cho văn bản rỗng → bị loại no-content (hạn chế đã biết).
